# Демонстрационный сайт банка

Минимальный рабочий MVP под ваш запрос:

- Главная с условиями по вкладам и займам.
- Регистрация/авторизация по логину и паролю.
- Опциональная привязка Telegram-аккаунта.
- Анонимный топ по вкладам и займам с добровольным раскрытием логина.
- Расширенная таблица займов в формате Excel-подобного отчёта (процент, даты, возврат, прибыль, заметки).
- KPI: всего сделок, закрытые/неизвестные, чистая прибыль, оборот, X123.
- Конфиденциальная таблица показывается только разрешённым пользователям с кодом доступа.

## Формула X123

`X123 = (чистая прибыль / оборот) * 100%`

## Как открыть сайт

1. В корне проекта запустите:

```bash
python3 -m http.server 4173
```

2. Откройте в браузере:

- <http://localhost:4173>

3. Остановить сервер: `Ctrl + C`.

## Доступ к конфиденциальной таблице

- Войти нужно под разрешённым логином (список в `app.js`: `CONFIDENTIAL_ALLOWED_USERS`).
- При входе/регистрации введите код доступа в поле `Код доступа к конфиденциальной таблице`.
