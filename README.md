# ОДКБ - Для своих! (MVP с backend-слоем)

Минимальный рабочий MVP под ваш запрос:

- Главная с офферами: «Вклады +10% всего через 31 день!» и «Займы от 25% до 30 дней».
- Открытая статистика + дополнительная метрика (средняя сделка и суммарный заработок).
- Регистрация/авторизация по логину и паролю.
- Опциональная привязка Telegram-аккаунта.
- Анонимный топ по вкладам и займам с добровольным раскрытием логина.
- Расширенная таблица займов + сортировка/поиск/CSV-экспорт.
- KPI: всего сделок, закрытые/неизвестные, чистая прибыль, оборот, X123.
- Конфиденциальная таблица показывается только разрешённым пользователям с кодом доступа.
- Пасхалка: Coin Tap с редкими золотыми монетами.
- Платежи: **только Telegram-бот + крипта (TON/USDT)**.
- Добавлен backend-слой `server.js` для:
  - API создания крипто-платежа,
  - сбора телеметрии клиентских событий,
  - выдачи краткой сводки по телеметрии.

## Формула X123

`X123 = (чистая прибыль / оборот) * 100%`

## Как запускать теперь (рекомендуется)

```bash
node server.js
```

Открыть: <http://localhost:4173>

> Можно и через `npm start` (если используете npm).

## Backend API

- `POST /api/payments/telegram-crypto/create`
  - принимает payload платежа,
  - возвращает `paymentId`, `deepLink`, `wallet`, `network`.
- `POST /api/telemetry/collect`
  - принимает клиентское событие,
  - сохраняет его в `data/telemetry.log.ndjson`.
- `GET /api/telemetry/summary`
  - сводка по числу событий и последние записи.

## Сбор информации (в рамках закона)

Backend и фронтенд сейчас собирают техническую и продуктовую телеметрию для аналитики в рамках эксплуатации сервиса:

- продуктовые события (вход, регистрация, отправка платежа, клики по ключевым действиям и т.д.);
- клиентский контекст: страница, реферер, язык, платформа, user-agent, timezone, screen;
- серверный контекст: IP/прокси-IP, host, origin, method, path, timestamp.
